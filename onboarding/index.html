    Onboarding

    🚀 Onboarding — Bienvenue dans le Projet Quant System Ce guide te permet de prendre en main le projet rapidement et efficacement.

    🧭 1. Comprendre la structure Le projet est organisé en familles fonctionnelles :

    moteur quantitatif → data/, indicators/, modules/, strategy/, backtest/

    interfaces → interface/, interface_pilotage/

    exports → exports/

    documentation → docs/, documentation_md/

    tests → tests/

    scripts → scripts/

    ⚙️ 2. Installation bash git clone cd quant_system python -m venv .venv source .venv/bin/activate pip install -r requirements.txt ▶️ 3. Lancer le moteur Le fichier main.py est le point d’entrée principal du projet.

    Pour l’exécuter :

    bash python main.py ⚠️ Important : Si main.py contient du code Streamlit, tu verras un avertissement :

    Code Warning: to view this Streamlit app on a browser, run it with: streamlit run main.py Dans ce cas, lance plutôt :

    bash streamlit run main.py Résumé :

    script Python classique → python main.py

    dashboard Streamlit → streamlit run main.py

    Les deux comportements sont normaux.

    🖥️ 4. Lancer un dashboard Certaines interfaces du projet utilisent Streamlit. Elles se trouvent dans :

    Code interface/ Exemple 1 — Dashboard de prédictibilité bash streamlit run interface/predictability_dashboard.py Exemple 2 — Dashboard PropFirm bash streamlit run interface/propfirm_dashboard.py ⚠️ Important Ne jamais lancer un fichier Streamlit avec :

    bash python fichier.py Toujours utiliser :

    bash streamlit run fichier.py Lancer le menu principal bash streamlit run main.py 🧠 5. Explorer le moteur quantitatif (pas à pas) L’objectif est de comprendre le pipeline interne.

    5.1 Suivre le pipeline dans le code Ouvrir main.py

    repérer les fonctions appelées

    identifier l’ordre :

    Code data → indicators → modules → strategy → backtest → exports Explorer data/

    chargement et validation des données

    Explorer indicators/

    indicateurs techniques

    lien avec docs/reference/indicator_math.md

    Explorer modules/quant/

    structure, volatilité, orderflow, signaux avancés

    Explorer strategy/

    filtrage, consolidation, décision, risque, sizing

    Explorer backtest/

    boucle de simulation

    lien avec docs/architecture/diagrams/backtest_timing_diagram.md

    5.2 Construire une trace mentale En lisant dans cet ordre :

    Code data/ → indicators/ → modules/quant/ → strategy/ → backtest/ → exports/ Tu dois pouvoir te raconter :

    “Les données entrent ici, sont transformées là, enrichies ici, donnent des signaux là, la stratégie décide ici, le backtest simule là, puis les résultats partent dans exports/.”
