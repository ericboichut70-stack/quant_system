# 📘 documentation_md/README.md

🧭 Rôle du dossier documentation_md/

Le dossier documentation_md/ contient la documentation interne, rituelle, symbolique et opérationnelle du projet.
Il ne s’agit pas de documentation technique, mais d’un espace dédié à :

tes rituels de performance

tes fiches d’ouverture et de clôture

tes cosmogrammes

tes scripts d’automatisation documentaire

tes index consolidés

tes exports internes

tes protocoles de travail

C’est un espace vivant, organique, narratif, qui accompagne l’évolution du projet.

📂 Contenu typique

Le dossier contient :

Rituels
fiches d’ouverture

fiches de clôture

rituels de performance

cosmogrammes

Scripts d’automatisation
génération d’annexes

génération d’index

Exports internes
logs

annexes générées

Documentation narrative
notes

réflexions

protocoles internes

🔧 Intégration dans le projet

Ce dossier est séparé de docs/ pour éviter toute confusion :

docs/ = documentation technique officielle

documentation_md/ = documentation interne, rituelle, narrative, automatisée

Cette séparation est essentielle pour maintenir une architecture documentaire propre.

📌 Bonnes pratiques

Ne pas mélanger technique et rituel.

Garder une structure simple et lisible.

Documenter les scripts d’automatisation.

Utiliser ce dossier comme espace de travail interne
