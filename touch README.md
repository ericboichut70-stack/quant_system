# 📊 Professeur SMC – Bot pédagogique de lecture de marché

**Version Alpha – Octobre 2025**

---

## 🎯 Objectif

Professeur SMC est un bot modulaire conçu pour :
- Lire la structure du marché selon les concepts Smart Money (SMC)
- Détecter les signaux techniques et institutionnels
- Simuler des scénarios pédagogiques
- Expliquer les motifs d’entrée et de sortie
- Enseigner la logique du prix à travers une interface interactive

---

## 🧩 Modules intégrés

- **Structure SMC** : BOS, ChOCh, HH/HL, LH/LL, zigzag
- **Zones institutionnelles** : Order Blocks, Fair Value Gaps, Mitigation
- **Analyse technique** : Volatility, Liquidity, Orderflow, Convergence
- **Lecture multi-timeframe** : M1, M5, M15
- **Radar des marchés** : espérance mathématique maximale
- **Optimisation des ordres** : limit, stop, market
- **Scénarios pédagogiques** : replay, explication, validation
- **Dashboard interactif** : version technique et version ludique
