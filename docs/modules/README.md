# 🧩 Modules — Documentation des Modules Quantitatifs

Ce dossier contient la documentation détaillée de chaque module du moteur quantitatif.

Les modules décrivent les briques fonctionnelles spécialisées utilisées dans le pipeline :

- structure de marché  
- volatilité  
- orderflow  
- signaux avancés  
- optimisation  
- features  
- pipeline  
- attribution  
- utilitaires  

Chaque fichier de ce dossier documente un module spécifique, son rôle, ses entrées, ses sorties et son intégration dans le moteur.

Ce dossier complète :

- `docs/quant_engine/` (vue globale du moteur)
- `docs/reference/` (principes et définitions)
- `docs/architecture/` (schémas et flux)
