# 🤝 How to Contribute — Guide de Contribution

Ce document explique comment contribuer efficacement au projet, que ce soit pour :

- ajouter un module  
- améliorer la documentation  
- corriger un bug  
- enrichir les interfaces  
- proposer une nouvelle fonctionnalité  

---

## 🧭 1. Pré-requis

- Python 3.10+  
- Git  
- Environnement virtuel recommandé  
- Connaissance de base du pipeline quantitatif  

---

## 🧱 2. Processus de Contribution

## 2.1 Fork & Branch

1. forker le dépôt  
2. créer une branche dédiée :
git checkout -b feature/nom_fonctionnalite

## 2.2 Développement

- respecter les conventions (`coding_standards.md`)  
- suivre la structure (`folder_structure.md`)  
- documenter les modules ajoutés  
- ajouter des tests  

## 2.3 Tests

Exécuter les tests :
pytest

## 2.4 Documentation

- mettre à jour les fichiers concernés  
- ajouter des schémas si nécessaire  
- vérifier les liens internes  

## 2.5 Pull Request

Inclure :

- description claire  
- justification  
- captures ou exemples  
- checklist de tests  

---

## 🧬 3. Types de Contributions

- modules quantitatifs  
- indicateurs  
- stratégies  
- améliorations du backtest  
- dashboards  
- outils CLI  
- documentation  
- exports  

---

## 🧩 4. Règles de Qualité

- pas de duplication  
- pas de dépendances circulaires  
- code lisible  
- tests obligatoires  
- documentation obligatoire
