# 🧪 Experiment Tracking — Suivi des Expériences

Ce document décrit les bonnes pratiques pour suivre, organiser et documenter les expériences quantitatives.

---

## 🧭 1. Objectifs

- reproductibilité  
- auditabilité  
- comparaison des résultats  
- traçabilité des paramètres  
- archivage des modèles  

---

## 🧱 2. Éléments à Suivre

## 2.1 Paramètres

- indicateurs  
- modules quantitatifs  
- stratégie  
- backtest  
- volatilité  
- régimes  

## 2.2 Données

- source  
- période  
- fréquence  
- transformations  

## 2.3 Résultats

- métriques  
- courbes  
- logs  
- signaux  

---

## 🧬 3. Outils Recommandés

- dossiers versionnés  
- fichiers JSON de configuration  
- notebooks annotés  
- exports structurés  

---

## 🧪 4. Bonnes Pratiques

- nommer clairement chaque expérience  
- conserver les résultats bruts  
- documenter les conclusions  
- éviter les modifications silencieuses
