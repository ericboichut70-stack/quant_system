    Quant Engine — Machine Learning

    Objectif du module Le module Machine Learning prépare l’intégration future de modèles prédictifs dans le moteur quantitatif. Il n’est pas encore actif dans la version actuelle, mais il définit :

    la structure d’accueil des modèles

    les points d’entrée dans le pipeline

    les formats de données attendus

    les règles d’interprétation des prédictions

    Il répond à la question :

    « Comment intégrer un modèle ML dans un pipeline quantitatif déjà structuré ? »

    Rôle du module Le module ML a pour vocation de :

    charger un modèle entraîné

    préparer les features nécessaires

    produire une prédiction exploitable

    transmettre cette prédiction au module quant ou strategy

    rester totalement optionnel dans le pipeline

    Il doit fonctionner sans casser la logique existante.

    Approche générale L’intégration ML suit trois principes :

    1. Isolation

    Le modèle ML ne doit pas modifier les modules existants. Il agit comme une couche additionnelle.

    1. Compatibilité

    Les prédictions doivent être compatibles avec :

    les signaux quantitatifs

    les règles de stratégie

    le moteur de risque

    1. Extensibilité

    Le module doit pouvoir accueillir :

    des modèles statistiques

    des modèles de régression

    des classifieurs

    des réseaux neuronaux

    des modèles séquentiels (LSTM, Transformers)

    Types de modèles envisagés

    1. Modèles de classification

    Prédire un mouvement haussier ou baissier. Exemples :

    logistic regression

    random forest

    gradient boosting

    1. Modèles de régression

    Prédire un retour attendu ou une amplitude. Exemples :

    régression linéaire

    XGBoost

    réseaux neuronaux

    1. Modèles séquentiels

    Prédire des patterns temporels complexes. Exemples :

    LSTM

    GRU

    Transformers

    Intégration dans le pipeline Le module ML peut intervenir à deux niveaux :

    Option A — Avant les signaux Le modèle produit une prédiction brute, utilisée comme feature supplémentaire.

    Option B — Après les signaux Le modèle produit une décision ou un score directement exploitable par la stratégie.

    Les deux approches sont compatibles.

    Structure interne Le module ML pourra fournir :

    ml_features

    ml_prediction

    ml_score

    ml_confidence

    Ces éléments seront ajoutés au contexte du pipeline.

    Flux interne Données → indicateurs → features ML → modèle ML → prédiction → signaux / stratégie → risque → backtest
