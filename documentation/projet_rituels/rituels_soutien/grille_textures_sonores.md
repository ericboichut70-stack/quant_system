# 🎶 Grille des textures sonores — Soutien modal

---

## 🎵 Paramètres par couche

| Couche sonore      | Instrument / source | Texture           | Rôle rituel                  |
|--------------------|---------------------|------------------|------------------------------|
| Bourdon            | Harmonium / voix grave | Continu, dense    | Base vibratoire, mémoire     |
| Accord plaqué      | Orgue / synthé      | Large, enveloppant | Soutien harmonique           |
| Arpège             | Harpe / guitare     | Fluide, léger     | Circulation, transmission    |
| Résonance finale   | Cloche / cymbale    | Éthérée, diffuse  | Scellage, silence suspendu   |

---

## 🕊️ Usage rituel

- Chaque texture est superposée pour créer une **atmosphère enveloppante**  
- Le bourdon reste la base constante  
- Les accords et arpèges enrichissent la mémoire sonore  

---

## 🏛️ Finalité

Cette grille inscrit les **textures sonores** comme repères auditifs,  
garantissant la **cohérence et la transmissibilité** du soutien modal.
