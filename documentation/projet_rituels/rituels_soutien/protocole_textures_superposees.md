# 🎶 Protocole de textures superposées — Rituel sonore

---

## 🎧 Étapes

1. **Entrée** : bourdon seul (La2), 4 temps  
2. **Superposition 1** : accords plaqués (Am → Dm → E → Am), intensité mezzo-forte  
3. **Superposition 2** : arpèges légers, synchronisés avec les vers chantés  
4. **Superposition 3** : résonances croisées (grave ↔ aigu, diffus ↔ dense)  
5. **Finale** : cloche ou cymbale, silence suspendu de 12 temps  

---

## 🎶 Indications techniques

- Tempo : ♩ = 60  
- Intensité : crescendo → diminuendo  
- Instruments : harmonium, orgue, harpe/guitare, cloche ou cymbale  
- Format : mono ou stéréo, 44.1 kHz  

---

## 🕊️ Usage rituel

- Les textures superposées inscrivent la **stratification sonore** dans une unité cohérente  
- Chaque couche contribue à la **mémoire auditive** du cycle  
- Le silence final devient le sceau ultime  

---

## 🏛️ Finalité

Ce protocole garantit la **reproductibilité des textures superposées**,  
et inscrit le rituel dans une **mémoire sonore transmissible**.
