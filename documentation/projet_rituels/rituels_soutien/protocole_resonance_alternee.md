# 🎶 Protocole de résonance alternée — Rituel sonore

---

## 🎧 Étapes

1. **Entrée** : voix grave + bourdon, intensité pianissimo  
2. **Alternance 1** : voix médiane résonne, voix grave suspendue  
3. **Alternance 2** : voix aiguë résonne, voix médiane suspendue  
4. **Fusion** : toutes les voix résonnent ensemble, crescendo collectif  
5. **Finale** : extinction progressive, silence suspendu de 12 temps  

---

## 🎶 Indications techniques

- Tempo : ♩ = 60  
- Intensité : crescendo → diminuendo  
- Instruments : voix collectives, harmonium, cloche ou cymbale  
- Format : mono ou stéréo, 44.1 kHz  

---

## 🕊️ Usage rituel

- La résonance alternée inscrit la **respiration cyclique** du groupe  
- Chaque alternance devient une **trace auditive partagée**  
- Le silence final scelle la mémoire du cycle  

---

## 🏛️ Finalité

Ce protocole garantit la **reproductibilité de la résonance alternée**,  
et inscrit le rituel dans une **mémoire sonore transmissible**.
