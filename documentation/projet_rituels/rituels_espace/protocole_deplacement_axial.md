# 🧭 Protocole de déplacement axial — Mise en scène rituelle

---

## 📐 Configuration

- Axe Nord-Sud : Clôture ↔ Ouverture  
- Axe Est-Ouest : Transmission ↔ Renaissance  
- Centre : mémoire scellée

---

## 🎶 Étapes

1. **Clôture (Nord)** : pas vers le centre, bras joints  
2. **Transmission (Est)** : pas latéraux, bras ouverts  
3. **Ouverture (Sud)** : pas vers l’extérieur, bras levés  
4. **Renaissance (Ouest)** : pas circulaires, retour au point de départ  

---

## 🕊️ Usage rituel

- Les déplacements suivent les axes cardinaux  
- Chaque mouvement est synchronisé avec les vers chantés  
- Le centre reste le point de convergence

---

## 🏛️ Finalité

Ce protocole axial garantit la **cohérence des déplacements**,  
et inscrit le rituel dans une **géométrie lisible et transmissible**.
