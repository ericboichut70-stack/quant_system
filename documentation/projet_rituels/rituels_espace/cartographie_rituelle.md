## 🗺️ Légende narrative

### 🔒 Clôture  

« Ce qui est accompli… se scelle.  
Le centre devient mémoire,  
le silence devient trace. »

### 🔗 Transmission  

« Ce qui est scellé… se transmet.  
Les bras s’ouvrent,  
la mémoire circule. »

### 🌅 Ouverture  

« Ce qui est transmis… s’ouvre.  
Le souffle s’élève,  
la spirale s’étend. »

### 🌱 Renaissance  

« Ce qui est ouvert… renaît.  
Le cercle s’élargit,  
le cycle recommence. »
