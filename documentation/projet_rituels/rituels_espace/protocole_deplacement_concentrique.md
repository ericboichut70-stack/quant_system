# 🔄 Protocole de déplacement concentrique — Mise en scène rituelle

---

## 📐 Configuration

- Déplacement du centre vers les cercles extérieurs  
- Retour concentrique vers le centre  
- Mouvement synchronisé avec les vers chantés  

---

## 🎶 Étapes

1. Officiants : déplacement concentrique vers le cercle médian, voix grave  
2. Participants : déplacement concentrique vers le cercle extérieur, voix claire  
3. Convergence finale : retour simultané vers le centre, silence de 12 temps  

---

## 🕊️ Usage rituel

- Le déplacement concentrique inscrit la **dynamique d’expansion et de retour**  
- Le centre devient le **sceau de mémoire**  
- Silence final : immobilité totale, regard vers le centre  

---

## 🏛️ Finalité

Ce protocole inscrit le **déplacement concentrique** comme acte rituel,  
garantissant la **cohérence dynamique et transmissible** du cycle.
