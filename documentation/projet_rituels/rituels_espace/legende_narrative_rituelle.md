# 📘 Légende narrative — Cartographie rituelle

---

## 🔒 Clôture (Cercle fermé)

« Ce qui est accompli… se scelle.  
Le centre devient mémoire,  
le silence devient trace. »

## 🔗 Transmission (Cercle ouvert)

« Ce qui est scellé… se transmet.  
Les bras s’ouvrent,  
la mémoire circule. »

## 🌅 Ouverture (Spirale vers l’extérieur)

« Ce qui est transmis… s’ouvre.  
Le souffle s’élève,  
la spirale s’étend. »

## 🌱 Renaissance (Cercle élargi)

« Ce qui est ouvert… renaît.  
Le cercle s’élargit,  
le cycle recommence. »

---

## 🏛️ Finalité

Cette légende narrative renforce la **lisibilité symbolique** du schéma spatial,  
et inscrit chaque étape dans une **formule poétique transmissible**.
